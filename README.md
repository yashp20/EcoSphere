# 🌍 EcoSphere — Smart Sustainability Recommendations

EcoSphere is a full-stack sustainability assistant that analyzes your household energy usage and recommends the most impactful eco-friendly upgrades. From solar to EV chargers, EcoSphere guides users toward reducing carbon footprint and saving money — backed by real energy data and incentives.

---

## ✨ Features

- ⚡ Personalized **carbon impact calculations**
- 🏠 Recommendations for:
  - Solar panels
  - Clean energy providers
  - Home electrification upgrades
- 💸 Local incentive + rebate insights
- 📊 Interactive results dashboard
- 🔐 Auth handled with Clerk
- 🎨 Modern responsive UI with Tailwind CSS

---

## 🧱 Tech Stack

| Area | Technology |
|------|------------|
| Frontend | React + Vite, Tailwind CSS |
| Backend | Python (FastAPI / Flask — update based on your code) |
| Auth | Clerk |
| Data Layer | Recommendation engine with energy provider + incentive data |
| Build Tools | Node.js, Vite |
